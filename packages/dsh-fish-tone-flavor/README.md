# dsh-fish-tone-flavor

[`dsh-fish-tone`](../dsh-fish-tone) 的**附属包**：可爱一点、抽象一点，外加一个热梗库。

主插件是中性的 —— 它只把话往人的方向掰一点点，不替用户决定性格。
性格是偏好，会变；所以它被拆到这里，而且**默认关**。

## 默认关，开了才生效

| | 关着（默认） | 开着 |
|---|---|---|
| prompt | 一个字都不加 | 挂一节「性格层」（可爱 / 抽象，密度很低） |
| `fish_flavor` | 能用，但只有你手动调用才动 | 参数缺省走设置页里的档 |
| `fish_meme` | 一直能用 | 一直能用 |

卸载这一包，主插件照常工作。装回去也一样。

## 两个工具

### `fish_meme` —— 查梗

```text
fish_meme({ query: "破防" })
fish_meme({ kind: "construction" })      // 只看句式：！？X？！ / 单字判词 / X了
fish_meme({ vibe: "cute", limit: 5 })
fish_meme({ random: true })
```

库里分两类：

| 类 | 长什么样 | 例子 |
|---|---|---|
| 词 | 一个词收掉一个态度 | 破防、典、绝了、尊嘟假嘟 |
| 句式 | 一套模板，往格式里填 | `！？{一句话}？！`、`{X}了`、`典/孝/急/乐/蚌/赢`、`当个事儿办` |

每条给：梗、年份、味道（cute / abstract / ironic / broken / work / heal / hype / retro / slacker / fun）、
一句话意思、怎么用、来源，以及它在本机语料里出现过几次。

### `fish_flavor` —— 挂性格

```text
fish_flavor({ text: "...", mode: "cute" })      // 句尾挂软语气词
fish_flavor({ text: "...", mode: "abstract" })  // 句尾挂一个短梗
```

只加尾巴，不改句子：

- `cute`：呀 / 嘛 / 啦 / 哟 / 哦 / 呢
- `abstract`：典 / 绝了 / 离谱 / 逆天 / 这很难评 / 我不理解 / 就这 / 好家伙 / 绷不住了 / 笑死 / 已阅 / 那咋了 / 不讲不讲 / 抽象
- `shock`：句号换成 `？！`（`14.69？！`）。**只做基础款** —— `！？X？！` 是加码版，只有两个叠字（强强/电电）或抽象名词才用，插件不替人判断场合适不适合

密度 `low`（默认）≈ 每十几句一处，一段话最多三处。同一个 `seed` 给同一个结果。

抽象档会挑**判断句**下手：有「有点 / 挺 / 太 / 真的 / 感觉 / 觉得 / 拖 / 尬」这类评价词的句子优先，
而且从段尾往前找 —— 因为「后面那段有点拖，这很难评」读着顺，「配乐很低，这很难评」像硬塞。
找不到判断句就退回普通句尾。

跳过代码块、行内代码、URL、路径、表格、标题、列表 —— 这一条和主插件一致：
**写代码、报数字、给结论的时候，一个梗都不加。**

## 热梗库

`data/memes.json` **1000 条词** + `data/constructions.json` 24 条句式。

词的来源是 B 站两个梗科普号（「梗百科」991 个投稿、「十万个梗百科」992 个）加上 12 个关键词的热梗盘点，一共 2,641 个视频标题；每条都跑过本地 10 万条评论 + 107 万条弹幕，记了命中次数。

其中 **144 条有释义**，其余只登记了词、味道和语料频次。没有释义的查出来会明说「还没考据，别自己编意思」—— 宁可它说不知道，也不能让它瞎用。
另一个字段 `tail` 只有 16 条为真：能当句尾收口的就那么几个，「绝了」「典」「离谱」「这很难评」这一档。

句式那 24 条是按照你说的方向找的 —— 不是"某个词火了"，是"某种句式火了"：

| 句式 | 模板 | 评论 / 弹幕 |
|---|---|---:|
| X？！ | `{短名词}？！` 基础款；`！？{叠字/抽象名词}？！` 是加码版 | 11 / 478 |
| 啊？ | `啊？` | 50 / 745 |
| 就这？ | `就这？` | 56 / 208 |
| X了 | `{神/绝/拉/寄/麻}了` | 15 / 143 |
| 单字判词 | `典 / 孝 / 急 / 乐 / 蚌 / 赢` | 14 / 51 |
| 有点X，不确定，再看看 | `有点{X}，不确定，再看看` | 7 / 16 |
| 一整个X住 | `一整个{X}住了` | 5 / 9 |
| 当个事儿办 | `别让{X}做这个了 / 行，我回去说他 / 当个事儿办` | 0 / 0 |

（最后一行的「当个事儿办」是 2026 年上半年的新模板，采语料的时候还没进弹幕，先按官方报道收录。）

来源分三类，每条的 `source` 字段写着是哪一类：

- 官方盘点：新华社「2025 年度十大网络流行语」、B站 2025 年度弹幕「致敬」
- 平台报告：小红书 2026 十大热词（千瓜数据）、光明网 / 上观新闻 / 人民网的梗盘点
- B站弹幕常青梗：空降成功、前方高能、2333、爷青回…

每条还带 `corpus` 计数：这个梗在本地 28 万条去重 B 站评论 + 弹幕（170 个视频）里出现过几次、跨几个视频。
**计数按子串匹配，含少量误配**（「内卷」会撞上「卷入浩劫」），所以它只当参考，不当事实证明。
出处的判断以 `source` 为准。

库里的原文例句一律不入库 —— 只留聚合计数。
