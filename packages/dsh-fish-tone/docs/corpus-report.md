# 语病的结构框架（评论 / 弹幕分开量）

语病不是一张平铺的病历。拆到结构上看，B 站里能被看到的「不规范」其实是**五台不同的机器**在出错，
其中四台根本不在「语法」这一层。

| 框架 | 结构式 | 哪一步塌了 | 例 |
|---|---|---|---|
| **F1 输入法手滑** | `[同音字] → [正字]` | 拼音候选词上屏上错了 | 做为、因该、即然 |
| F1′ 助词错位 | `[状语] + 的 + [动词]` / `[动词] + 的 + [程度]` | 的 / 地 / 得 三合一，键盘上只有一个 de | 慢慢的说、跑的很快 |
| **F2 手速重复** | `X + X`（同一字或标点连打） | 手比眼快，同一个键敲了两次 | 我我、这这、。。、，， |
| **F3 语气加载** | `[句干] + [语气词]^n` | 情绪全压在句尾 | 吧吧、啊啊 |
| **F4 格式混用** | `[汉字] + [,.;:]` | 打完英文忘了切回中文输入法 | 挺好,真的 |
| **F5 书面语病** | 见下 | 长句的结构撑不住，塌了 | — |

F5 才是学校教的那套，它自己又能拆成几个固定壳子：

| 壳子 | 结构式 | 塌在哪 | 例 |
|---|---|---|---|
| 介词吞主语 | `[通过/经过/由于] + [短语] + 使 + [主句]` | 介词把主语吃掉了 | 通过这次分析使我知道了 |
| 否定叠加 | `[防止/避免] + [X] + 不 + [动词]` | 两个否定撞在一起，意思反了 | 防止事故不再发生 |
| 量词与复数打架 | `一 + [量词] + [名词] + 们` | 单数量词和复数标记同时出现 | 一个同学们 |
| 句式杂糅 | `原因是 + [X] + 造成的` | 两套句式叠在一个槽里 | 原因是数据太少造成的 |
| 同义反复 | `[约/大约] + [数量] + [左右]` | 一个意思说了两遍 | 大约三十分钟左右 |
| 成分赘余 | `[涉及/来自/付诸] + 于/到` | 介词多长出来一个字 | 涉及到、付诸于 |

## 一句结论

评论和弹幕**要分开看**：它们不是同一种语言。

- 评论是打字打出来的，有句子、有标点、会犯 F5（虽然也很少）；
- 弹幕是手速和情绪的产物，句子被压成一个词，F5 几乎不存在。

所以插件的配额按**评论**校准（弹幕那档只作为上限参考）。
