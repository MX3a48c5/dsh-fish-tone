# dsh-fish-tone

**双向鱼群拓扑 · 人味插件。** 把话往人的方向掰一点点。

方法来自 [BV1BNnc6nEUa](https://www.bilibili.com/video/BV1BNnc6nEUa)（54 秒，22 段字幕），
能落地的部分就四条：

| 视频里的说法 | 插件里怎么落地 |
|---|---|
| 双向鱼群拓扑，每条鱼只跟前后两条鱼握手 | 正反两遍扫描：正向只看前一条，反向只看后一条。**没有任何全局优化** |
| 握完就学会了犹豫 | 邻居犹豫了，我也更容易犹豫（相邻传导，不是整段统一加） |
| 句尾加一点没用的东西：的 / 吧 / 就 | 尾巴表 `啊 啦 嘛 吧 的`，一句最多一个；「吧」只在建议句上，「就」删了 |
| 越没用越像人 | 输出里带 `uselessness`（插进去的字 ÷ 原文长度） |

## 两个半侧

1. **systemPrompt 一节 `fish-tone:voice`（order 920）** —— 真正起作用的那半：让模型自己就这么说话。
2. **`fish_tone` 工具** —— 把一段已经写好的话确定性地掰一遍，用来救那些"一看就是报告"的草稿。

## 设置页（图形界面）

装好之后，**设置 → 人味插件**：

- **总开关**：关掉 = 把「说话的松紧」整节从系统提示里撤掉（当场生效，不用重启）
- **语病层**：开 = 扫掉大部分、留一点；关 = 一个都不留
- **掰多少**：关 / 轻 / 中 / 猛 四档，点了立刻改
- **种子**：同一个种子 + 同一段话 = 同一个结果
- **试一下**：输入框里打一句话，点「掰一下」，当场看结果和统计（尾巴 / 犹豫 / 废话 / 无用度）

配置存在插件目录的 `config.json`，宿主开 `/api/fish-tone` 提供 `status` / `config` / `preview` 三个接口。

## 装

**推荐**（会同时登记依赖、bundle 和客户端半端）：

```sh
dsh plugin --profile web add link:/path/to/dsh-fish-tone
```

**手动**（等价，改 profile 的 `cordis.patch.yml`）：

```yaml
- insert:
    - id: fish-tone
      name: dsh-fish-tone
      config:
        strength: light   # off | light | normal | max
        seed: 7
```

包放进 profile 的 `node_modules`（或软链）即可。装好后**重启一次 dsh**：宿主半端、
`/api/fish-tone` 和设置页都是在启动时装配的，Node 的 ESM 缓存不吃热更新。

## 用

```
fish_tone({ text: "……" })                       # light，直接给掰过的文字
fish_tone({ text: "……", strength: "max" })       # 会塞废话
fish_tone({ text: "……", format: "json" })        # 多给一份统计
fish_tone({ text: "……", seed: 42 })              # 同一个 seed → 同一个结果
```

## 不碰什么

默认 `protect: true`，以下一律原样穿过：

- 代码块（含围栏状态跨行）
- 行内代码、URL、文件路径、`--命令行参数`
- 标题、列表、表格、引用、命令与路径开头的行
- 没有中文的句子
- 已经带语气词的句尾、以冒号/顿号收尾的引出句
- 句尾的方括号表情：尾巴插在它**前面**（「藏得挺深的[doge]」，不是「[doge]的」）
- 挂不上去的搭配就不挂：特指问后面不挂「吧」「嘛」（不写「你干什么了吧」），
  「吧」只在建议 / 祈使句上（"那就先这样吧"），句尾的「就」整个删了；
  「的」只挂在「程度副词 + 形容词」的评价句上（"挺麻烦的"），比较句不挂
  （"音质比预期好的"是病句）

它只加字，不删字，不改数字，句子数不变。

## 三档

| 档 | 尾巴 | 首句犹豫 | 其他句犹豫 | 废话 |
|---|---|---|---|---|
| `off` | 0 | 0 | 0 | 0 |
| `light`（默认） | 0.15 | 0.4 | 0.03 | 0 |
| `normal` | 0.32 | 0.7 | 0.08 | 0.12 |
| `max` | 0.55 | 0.9 | 0.15 | 0.35 |

邻居挂了尾巴时，自己再 +0.25 —— 这就是"握手"。

## 语病层（数字是量出来的，不是拍的）

**评论和弹幕是分开采、分开量的** —— 它们不是同一种语言。条数按「条」算（同句不同人算两条），不按文本去重。

| 语料 | 条数（去重文本） | 字数 | 视频 | 语病密度 |
|---|---:|---:|---:|---:|
| 评论 | 24,587 | 126.7 万 | 397 | 1.61 / 千字（每 621 字一处） |
| 弹幕 | 1,026,257 | 851.9 万 | 279 | 1.66 / 千字（每 602 字一处） |

| 框架 | 是什么 | 评论命中 | 弹幕命中 |
|---|---|---:|---:|
| F1 输入法手滑 | 同音字上屏、的地得混用 | 285 | 1,032 |
| F2 手速重复 | 同个字/标点连打两次 | 682 | 7,450 |
| F3 语气加载 | 语气词、副词堆叠 | 71 | 929 |
| F4 格式混用 | 中文里夹英文标点 | 969 | 4,666 |
| F5 书面语病 | 成分残缺、杂糅、赘余 | 35 | 42 |

两边差得最狠的是 F5：评论 35 次、弹幕 42 次，各占自己总量的 1.7% 和 0.3%。
学校教的那套语法病，在两种语料里都接近于零。

插件写的是聊天式回复，按**评论**那档校准，再稍微留一点余量 —— 每 800 字一个：

| 字数 | 允许留的不明显语病 | 允许留的明显语病 |
|---|---|---|
| < 300 | 0 | 0 |
| 300–799 | 1 | 0 |
| 800–1999 | 字数 / 800 | 0 |
| ≥ 2000 | 字数 / 800 | 字数 / 2000 |

一条语病都没扫到时，按配额补「手滑」（语气词叠用 / 虚词连打 / 句号连打），最多三处 —— 
不然干净的稿子读完像校对过的。

规则表（`lib/grammar.js`，18 条，按框架分组）：

| 框架 | 规则 | 严重度 |
|---|---|---|
| F1 | 同音字（做为/因该/即然/必竟） | 不明显 |
| F1 | 状语该用「地」（慢慢的说） | 不明显 |
| F1 | 补语该用「得」（跑的很快） | 不明显 |
| F2 | 标点连打（。。/，，；`！！` 不算，那是表达） | 明显 |
| F2 | 虚词连打（我我/这这/就就） | 不明显 |
| F3 | 语气词叠用（吧吧/啊啊） | 不明显 |
| F3 | 副词重复（很很/非常非常） | 不明显 |
| F4 | 中文里夹英文逗号句号 | 不明显 |
| F5 | `通过…使…` 缺主语 | 明显 |
| F5 | `防止…不…` 说反 | 明显 |
| F5 | `一个同学们` 量词打架 | 明显 |
| F5 | `原因是…造成的` 句式杂糅 | 明显 |
| F5 | `本着…为原则` 句式杂糅 | 明显 |
| F5 | `约…左右` 同义反复 | 不明显 |
| F5 | `涉及到` / `来自于` 介词冗余 | 不明显 |
| F5 | `再次重申` / `彻底根除` 同义堆叠 | 不明显 |
| F5 | `很多同学们` 复数标记重复 | 不明显 |
| F5 | `非常太…` 程度副词撞绝对词 | 不明显 |

代码块、行内代码、URL、路径、命令行参数、表格、标题、列表**一律不查**。

两个入口：

- `fish_tone` 掰完自动过一遍（设置页「语病层」可关）
- `fish_grammar` 单独用：只查（`fix: false`）或修干净（`fix: true`）

完整的结构框架说明和逐条实测表见 [docs/corpus-report.md](docs/corpus-report.md)。

## 校准（拿真人评论当标尺）

`tools/calibrate.mjs` 拿一段**真人手写的短句**当"人味上限"（JSON 数组，或带 `content`/`text` 的对象数组），
每档跑 30 个种子：

```sh
node tools/calibrate.mjs 我的语料.json   # 不给文件就用内置中性样例跑通
```

下面的数字来自一段 13 条、平均 24 字的真人短评语料：

| 档位 | 改动率 | 尾巴率 | 插字比 | 平均插字 |
|---|---|---|---|---|
| off | 0.0% | 0.0% | 0.0% | 0 字 |
| **light** | **33.3%** | **8.5%** | **2.7%** | **0.7 字** |
| normal | 56.7% | 22.6% | 8.0% | 1.9 字 |
| max | 85.4% | 50.8% | 16.4% | 4.0 字 |

那批语料里真人自己的语气词收尾率是 **7.7%** —— `light` 的 8.5% 就贴着这条线。
（校准前 `light` 的改动率是 50.3%，因为短句也照犹豫；现在 40 字以内犹豫概率砍到四成。）

## 附属包：性格层

可爱 / 抽象 / 热梗**不在这个包里**。它们是偏好，不是语言能力，拆到了
[`dsh-fish-tone-flavor`](../dsh-fish-tone-flavor)：默认关，开了才挂一节性格层 prompt，
另带 77 条热梗（`fish_meme` 查梗、`fish_flavor` 挂尾巴），设置页里单独一页。

主插件不因为装没装它而改变一个字。

## 限制

- 尾巴是概率挂的。挂之前有一道硬闸（特指问不挂「吧」「嘛」，「吧」只挂建议句），
  闸内仍然不看语义——它能保证不是病句，保证不了"这句话挂尾巴刚好合适"。
- 废话只有三句，且只在 `max` 出现；`max` 是给人看的，不建议日常开。
- 中文为主。英文句子直接跳过。
- 它不保证读起来更好，只保证读起来更像人 —— 这两件事不是一回事。
